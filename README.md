# โฟลเดอร์เริ่มต้นสำหรับ workshop

**ไฟล์ `CLAUDE.md` ในโฟลเดอร์นี้คืออะไร:** เป็นคู่มือที่ Claude อ่านเองอัตโนมัติทุกครั้งที่ทำงาน
ในโฟลเดอร์นี้ (ไม่ต้องเปิดอ่าน ไม่ต้องทำอะไรกับมัน) **ไม่ต้องลบ** — มันช่วยให้ Claude สร้างระบบ
ให้คุณได้ถูกต้องตามที่ตั้งใจไว้ในคลาส

**วิธีใช้:**
1. เปิด Claude Desktop
2. เปิดโฟลเดอร์นี้เป็นโปรเจกต์ (แทนการสร้างโฟลเดอร์ใหม่เปล่าๆ)
3. พิมพ์ประโยคสูตรที่ได้รับในคลาสใส่ในแชต แล้วทำตามคู่มือได้เลย
